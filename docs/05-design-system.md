# Projeto Monizinha — Sistema Visual e Identidade da Interface

**Documento:** 05 — Design System
**Versão:** 1.0
**Data:** 06/08/2026
**Projeto:** Projeto Monizinha
**Produto público:** Artes de Monizinha
**Data-alvo da versão 1.0:** 08/08/2026

---

## Status por área

* **[HUB — VERSÃO 1.0]** Terá identidade visual própria como marca principal.
* **[CROCHÊ — VERSÃO 1.0]** Terá identidade visual própria, relacionada à marca principal.
* **[BOLOS FAKE — VERSÃO FUTURA]** Terá identidade visual definida em uma versão futura, preservando a ligação com a marca Artes de Monizinha.

Sempre que uma definição visual se referir exclusivamente a uma dessas áreas, ela deverá utilizar a identificação correspondente.

---

## 1. Objetivo

Este documento define as diretrizes visuais e os padrões de interface do Projeto Monizinha.

O sistema visual deverá:

* manter consistência entre as páginas;
* diferenciar o Hub da Loja de Crochê;
* preservar a identidade principal da Artes de Monizinha;
* facilitar a navegação;
* funcionar adequadamente em celulares;
* transmitir uma aparência artesanal e profissional;
* tornar produtos, categorias e ações fáceis de identificar;
* permitir a futura inclusão da Loja de Bolos Fake;
* reduzir decisões visuais improvisadas durante o desenvolvimento.

Este documento não define o logotipo final nem substitui arquivos gráficos oficiais da marca.

---

## 2. Princípios visuais

### Artesanal

A interface deverá representar produtos feitos manualmente, evitando uma aparência excessivamente industrial ou corporativa.

### Acolhedora

Textos, formas, imagens e componentes deverão transmitir proximidade e cuidado.

### Organizada

O caráter artesanal não deverá produzir uma interface desorganizada.

Os elementos deverão possuir:

* alinhamento;
* espaçamento;
* hierarquia;
* contraste;
* repetição consistente.

### Leve

A interface não deverá utilizar:

* excesso de cores;
* muitos efeitos;
* animações desnecessárias;
* fundos visualmente poluídos;
* componentes grandes sem função.

### Comercial

A aparência deverá ajudar o cliente a:

* encontrar produtos;
* compreender as opções;
* adicionar itens ao carrinho;
* iniciar contato pelo WhatsApp.

### Responsiva

A interface deverá ser planejada prioritariamente para dispositivos móveis.

## 3. Relação visual entre as áreas

A marca principal será:

```text
Artes de Monizinha
```

A Loja de Crochê será apresentada como:

```text
Artes de Monizinha Crochê
```

A futura loja será apresentada como:

```text
Artes de Monizinha Bolos Fake
```

As três áreas deverão compartilhar alguns elementos de reconhecimento, como:

* nome da marca;
* estilo tipográfico;
* tratamento de imagens;
* padrões de espaçamento;
* formato dos componentes;
* comportamento de botões;
* estrutura de navegação.

Cada loja poderá possuir:

* cor principal própria;
* banner próprio;
* elementos decorativos próprios;
* ícones próprios;
* linguagem visual própria.

---

## 4. Direção visual principal

A interface deverá combinar:

* fundo claro;
* áreas com cores suaves;
* textos escuros;
* cartões com bordas discretas;
* imagens grandes;
* cantos levemente arredondados;
* sombras moderadas;
* ícones simples;
* botões claramente identificáveis.

A aparência geral deverá ser:

```text
Artesanal + delicada + organizada + moderna
```

Não deverá parecer:

```text
Infantil demais
Luxuosa demais
Corporativa demais
Visualmente carregada
Genérica como um template não personalizado
```

## 7. Contraste

Os textos deverão manter contraste suficiente em relação ao fundo.

### Regras

* não utilizar texto rosa claro sobre fundo branco;
* não utilizar texto cinza muito claro;
* botões principais deverão possuir texto branco ou escuro, conforme o contraste;
* informações importantes não deverão depender apenas de cor;
* estados de erro deverão utilizar cor, texto e ícone;
* links deverão ser distinguíveis de textos comuns;
* focos de teclado deverão ser visíveis.

---

## 8. Tipografia

A interface utilizará no máximo duas famílias tipográficas principais.

### Fonte de títulos

Sugestão:

```text
Poppins
```

Uso:

* títulos;
* subtítulos;
* botões;
* menus;
* etiquetas.

Características desejadas:

* boa leitura;
* aparência moderna;
* formas arredondadas;
* compatibilidade com português.

### Fonte de texto

Sugestão:

```text
Inter
```

Uso:

* parágrafos;
* descrições;
* formulários;
* preços;
* mensagens;
* informações administrativas da interface pública.

### Alternativas de sistema

Caso as fontes externas não sejam carregadas:

```css
font-family: "Poppins", "Segoe UI", Arial, sans-serif;
```

```css
font-family: "Inter", "Segoe UI", Arial, sans-serif;
```

## 11. Sistema de espaçamento

Será utilizada uma escala baseada em múltiplos de quatro.

```text
4 px
8 px
12 px
16 px
24 px
32 px
48 px
64 px
80 px
```

### Uso sugerido

* 4 px: ajustes mínimos;
* 8 px: distância entre ícone e texto;
* 12 px: grupos pequenos;
* 16 px: espaçamento interno comum;
* 24 px: separação entre componentes;
* 32 px: separação entre blocos;
* 48 px: seções menores;
* 64 px ou mais: seções principais.

O Bootstrap poderá ser utilizado como referência para utilitários de margem e preenchimento.

---

## 12. Largura do conteúdo

O conteúdo principal não deverá ocupar toda a largura em telas grandes.

### Contêiner principal

```text
Largura máxima sugerida: 1200 px a 1320 px
```

### Textos longos

Parágrafos institucionais deverão utilizar largura menor para melhorar a leitura.

```text
Largura máxima sugerida: 700 px a 800 px
```

### Páginas de produto

A largura será dividida entre:

* galeria;
* informações;
* opções;
* ações.

Em dispositivos móveis, os elementos serão empilhados.

## 14. Sombras

As sombras deverão ser discretas.

### Sombra leve

```css
box-shadow: 0 2px 8px rgba(47, 41, 38, 0.08);
```

### Sombra de destaque

```css
box-shadow: 0 8px 24px rgba(47, 41, 38, 0.12);
```

### Regras

* não aplicar sombras fortes em todos os elementos;
* usar sombra principalmente em cartões e menus;
* combinar sombra com borda leve quando necessário;
* evitar efeitos tridimensionais exagerados.

## 15. Botões

Os botões deverão possuir hierarquia clara.

---

* acessar loja;
* adicionar ao carrinho;

Características:

* fundo na cor principal da área;
* texto branco;
* peso médio;
* altura confortável;
* foco visível;
* hover mais escuro.

Exemplo:

```text
Adicionar ao carrinho
```

## 15.2 Botão secundário

Uso:

* continuar comprando;
* voltar ao catálogo;
* ver detalhes;
* acessar informações complementares.

Características:

* fundo branco ou transparente;
* borda na cor principal;
* texto na cor principal.

---

Uso:

* atendimento;
* finalização;
* contato rápido.

Características:

Texto: branco

Todo botão deverá possuir:

* normal;
* hover;
* foco;
* ativo;
* desabilitado;
* carregamento, quando necessário.

Botões desabilitados deverão permanecer legíveis, mas visualmente menos destacados.

## 16. Links

Links no meio de textos deverão:

* possuir cor identificável;
* apresentar sublinhado em contextos de leitura;
* possuir foco visível;
* manter texto descritivo.

Evitar:

```text
Clique aqui
Saiba mais
Ver
```

Preferir:

```text
Conheça a Loja de Crochê
Leia nossa Política de Privacidade
Veja todos os produtos
```

---

## 17. Campos de formulário

Os formulários deverão utilizar:

* rótulo visível;
* campo;
* texto de ajuda, quando necessário;
* mensagem de erro;
* indicação de obrigatoriedade.

### Estrutura

```text
Rótulo
Campo
Texto de ajuda
Mensagem de erro
```

### Regras

* não utilizar apenas placeholder como rótulo;
* campos obrigatórios deverão ser identificados;
* erros deverão aparecer próximos ao campo;
* valores digitados não deverão ser apagados após erro;
* campos deverão possuir altura adequada para toque;
* áreas de texto deverão permitir redimensionamento controlado;
* opções deverão ter rótulos clicáveis.

---

## 18. Seleção de variações

As variações dos produtos poderão utilizar:

* `select`;
* radio buttons;
* checkboxes;
* campos de texto;
* campos numéricos;
* áreas de texto.

### Radio buttons

Recomendados quando:

* existirem poucas opções;
* o cliente precisar visualizar todas;
* apenas uma escolha for permitida.

### Select

Recomendado quando:

* existirem muitas opções;
* o espaço em tela for limitado.

### Checkbox

Recomendado quando:

* várias escolhas puderem ser selecionadas.

### Campo de texto

Recomendado para:

* cor personalizada;
* observação;
* detalhe específico.

A interface deverá informar claramente quais opções são obrigatórias.

### Características

* fundo branco;
* borda discreta;
* imagem proporcional;
* texto alinhado;
* botão visível;
* altura visualmente equilibrada.

## 21. [CROCHÊ — VERSÃO 1.0] Card de produto

Deverá conter:

* imagem principal;
* categoria;
* nome do produto;
* descrição curta;
* preço-base ou “Sob consulta”;
* indicação de personalização, quando aplicável;
* link para detalhes.

### Comportamento

* imagem com proporção consistente;
* nome limitado a uma quantidade razoável de linhas;
* card inteiro poderá ser clicável, desde que acessível;
* botão “Ver detalhes” permanecerá disponível;
* produtos inativos não serão exibidos.

## 22. Selos

Selos poderão representar:

* destaque;
* novo;
* personalizável;
* sob consulta;
* em breve;
* artesanal;
* indisponível.

### Regras

* utilizar textos curtos;
* não depender apenas de cor;
* limitar a quantidade por card;
* manter contraste;
* não ocultar partes importantes da imagem.

---

## 23. Preços

### Produto com preço-base

Exemplo:

```text
A partir de R$ 45,00
```

### Produto sob consulta

Exemplo:

```text
Valor sob consulta
```

### Produto com variação

A interface deverá informar quando:

* o preço muda conforme tamanho;
* opções acrescentam valor;
* o valor final depende de confirmação.

A versão 1.0 não deverá induzir o cliente a acreditar que o valor exibido é definitivo quando houver personalizações.

---

## 24. Imagens de produtos

As imagens serão um dos principais elementos do site.

### Requisitos

* boa resolução;
* iluminação adequada;
* produto centralizado;
* fundo pouco poluído;
* proporção consistente;
* carregamento otimizado;
* texto alternativo.

### Proporção sugerida para cards

```text
1:1
```

ou:

```text
4:5
```

Uma única proporção principal deverá ser escolhida durante a implementação.

### Galeria

A página de produto poderá possuir:

* imagem principal;
* miniaturas;
* navegação entre imagens;
* ampliação;
* suporte a toque.

---

## 25. Banners

### [HUB — VERSÃO 1.0]

* marca;
* frase curta;
* imagem artesanal;
* botão para a Loja de Crochê.

O banner deverá apresentar:

* identidade da loja;

* texto legível;
* imagem otimizada;
* não depender de texto dentro da própria imagem;
* altura reduzida em dispositivos móveis;
* ação principal claramente visível.

---

## 26. Cabeçalho

O cabeçalho deverá possuir:

* logotipo ou nome;
* navegação;
* carrinho, quando estiver na Loja de Crochê;
* acesso ao WhatsApp;
* menu móvel.

### Comportamento visual

* fundo claro;
* borda inferior discreta;
* altura moderada;
* item ativo identificado;
* ícones alinhados;
* menu móvel simples.

O cabeçalho do Hub e o da Loja de Crochê poderão utilizar cores e elementos diferentes.

---

## 27. Rodapé

O rodapé deverá possuir contraste suficiente em relação ao conteúdo.

### Conteúdo

* marca;
* navegação;
* contato;
* redes sociais;
* Política de Privacidade;
* informação de direitos autorais.

### Estilo

O Hub poderá utilizar:

```text
Rosa escuro ou marrom
```

A Loja de Crochê poderá utilizar:

```text
Terracota escuro
```

O texto deverá permanecer legível.

---

## 28. Breadcrumbs

Os breadcrumbs deverão utilizar:

* fonte menor;
* cores secundárias;
* separadores simples;
* último item sem link.

Exemplo:

```text
Início / Crochê / Acessórios / Chaveiro artesanal
```

Em dispositivos móveis, poderão quebrar linha sem causar rolagem horizontal.

---

## 29. Carrinho

### Item do carrinho

Deverá exibir:

* imagem;
* nome;
* opções;
* quantidade;
* preço-base;
* ações.

### Desktop

Poderá utilizar estrutura em linha ou tabela adaptada.

### Mobile

Deverá utilizar cards empilhados.

### Resumo

Deverá destacar:

* quantidade de itens;
* subtotal estimado, quando aplicável;
* indicação de valores sob consulta;
* botão de finalização.

---

## 30. Mensagens e alertas

As mensagens deverão possuir:

* ícone;
* título ou texto;
* cor funcional;
* possibilidade de fechamento, quando apropriado.

### Exemplos

```text
Produto adicionado ao carrinho.
Selecione as opções obrigatórias.
Este produto está indisponível.
Seu carrinho está vazio.
O valor final será confirmado pelo WhatsApp.
```

Mensagens importantes deverão permanecer visíveis por tempo suficiente para leitura.

---

## 31. Modais

Modais deverão ser utilizados com moderação.

Usos possíveis:

* ampliar imagem;
* confirmar limpeza do carrinho;
* informar ação importante.

Não deverão ser utilizados para:

* navegação principal;
* formulários longos;
* apresentar todas as informações de produto;
* substituir páginas necessárias.

---

## 32. Animações

A versão 1.0 utilizará poucas animações.

### Permitidas

* transições de hover;
* abertura de menu;
* expansão de FAQ;
* mudança de imagem;
* confirmação de item adicionado;
* rolagem suave em contextos adequados.

### Evitar

* elementos piscando;
* movimentos contínuos;
* parallax pesado;
* animações longas;
* efeitos que atrasem ações;
* animações que dificultem acessibilidade.

Usuários com preferência por movimento reduzido deverão ser respeitados quando possível.

## 33. Responsividade

Serão considerados os breakpoints do Bootstrap.

### Faixas principais

```text
Até 575 px: celulares pequenos
576 px a 767 px: celulares grandes
768 px a 991 px: tablets
992 px a 1199 px: desktops
1200 px ou mais: telas grandes
```

### Diretrizes

* começar pelo layout móvel;
* aumentar colunas progressivamente;
* evitar tamanhos fixos excessivos;
* utilizar imagens responsivas;
* impedir rolagem horizontal;
* testar formulários em telas pequenas;
* manter ações principais acessíveis.

## 49. Decisões fixadas

Para a versão 1.0:

1. O Hub e a Loja de Crochê terão identidades relacionadas, mas distintas.
2. A interface será planejada prioritariamente para celulares.
3. Bootstrap será utilizado como base.
4. Bootstrap será personalizado.
5. O Hub utilizará rosa artesanal como cor principal inicial.
6. A Loja de Crochê utilizará terracota como cor principal inicial.
7. A paleta poderá receber pequenos ajustes após a inclusão das imagens reais.
8. Serão utilizadas no máximo duas famílias tipográficas principais.
9. Poppins será a fonte sugerida para títulos.
10. Inter será a fonte sugerida para textos.
11. Bootstrap Icons será a biblioteca inicial de ícones.
12. Cards terão bordas discretas e cantos moderadamente arredondados.
13. As imagens terão papel central na apresentação.
14. O WhatsApp terá ação visual destacada.
15. Bolos Fake será apresentado somente como “Em breve”.
16. A interface não utilizará animações pesadas.
17. A acessibilidade não poderá depender somente das cores.
18. Textos importantes não serão incorporados exclusivamente em imagens.
19. Produtos sob consulta deverão ser claramente identificados.
20. Alterações visuais que comprometam o funcionamento não terão prioridade sobre o lançamento.
